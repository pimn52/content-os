# Content OS 落地路线

当前事实、唯一进行中的任务和许可边界见 [STATUS.md](../../STATUS.md)。旧 C4 原生加载器研究与旧包编号不再是执行队列。

| 顺序 | 结果 | 通过标准 |
|---|---|---|
| P6 收口 | 明确当前样片结论 | 保留失败与质量证据，不把预检成功当成品；已完成 |
| 架构减负 | 缩短普通创作到成片路径 | 实际调用与代码证据支持合并；净删复杂度；保留权利、预算和 QA |
| 第一条视频 | 普通 UI 一次输入走完新主题 | 产品自主规划、生成旁白/人物画面、质检和渲染；中途人工或 Codex 纠偏不计通过；记录用时与调用，真人判断确切成片可发布 |
| 第二主题 | 同一路径重复 | 不依赖手工脚本填分镜、裁切、子任务；记录用时、操作、返工和成本 |

每次只打开当前最小改动。真实模型或 Render 调用须有确切输入、预算和停止条件；失败后不自动重试。优先复用同文案、同项目、同权利条件下已认可的素材。
