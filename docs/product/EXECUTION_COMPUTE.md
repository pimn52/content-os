# 执行、能力与预算

本页是 ProductionRun/Job、实际 provider/model、预算、幂等、租约、失败与恢复的唯一权威来源。跨场景、Voice、Talking、素材与渲染的有界资源排序见[生产资源调度](PRODUCTION_SCHEDULING.md)。

ProductionRun 是普通创作执行入口。预检根据整条方案返回素材、Voice、Talking、渲染需求以及当前阻塞；Job/Worker 执行具体操作，提供商适配器只负责其调用。

## 必要准入

- 素材权利在入库登记，人物同意在 Profile 登记；普通 Run 继承记录，不重复索权。派发前核验素材哈希、适配、历史重复、当前实际 provider/model 配置与预算。能力档、非商业标记和许可声明缺失只影响日志与用途限制，不新增普通制作门禁。
- 能力有夹具、真实运行、正常 UI、可重复性不同证据级别；旧配置或旧样本不证明新环境能力。
- 调用前预约预算与幂等键，完成/失败/不明状态持久结算。费用未知时保持未知；不得跳过限制或借重试扩充额度。
- 普通规划的视频用途核验对已核价的官方 Moonshot `kimi-k2.6` 按输入上下文与实际输出上限预留保守金额，响应后分别记录输入、输出、缓存 Token 和价格日期。缺少可信用量时不伪造实付或释放原预留；按单价推算不等于账单实扣。其他模型、币种和旧视觉入口仍按实际已知范围处理。
- 本地资源以有界租约避免 Voice/Talking 同机冲突。运行环境准备服务于当前调用，不为每次任务重复完整原生证明研究。

## 普通界面

用户输入主题后，ProductionRun/Job/Worker 连续完成规划、预检、生成、QA 与渲染。普通界面显示进度、真实用时、成本及可恢复原因；中途阶段不反复索要批准。能力、预算、幂等与质量检查仍在调用边界执行，失败保留证据。

自动 Run 的 Voice/Talking 当前结果通过本 Run 技术 QA 后直接进入下一步；子片人工判断、精确预览、连续性审核和运行准入只属于显式手动/历史流程，不出现在自动制作区。最终成片判断仍由创作者完成。

运行配置可在界面保存本机凭据文件、模型与服务路径；不保存密钥正文。空项沿用启动配置，保存后待当前制作结束并重启服务生效，不能据配置存在推定模型可用。

正常链路的唯一有效成片自动成为作品当前输出，沿既定发布设置继续。用户修改、返工或生成对比版时，候选留在同一作品；界面在选版、多版导出等决策处显示占用及发布影响，生成前不要求最终选版。试做与正式创作使用同一产品链路，关系规则见[媒体资产与选择](MEDIA_ASSET_SYSTEM.md)。

## 当前能力与缺口

普通预检、Run/Job、预算账本及部分 Voice/Talking/Render 路径已有。实时 Worker 可用性、未知费用与故障恢复仍须据实展示；普通 UI 端到端和第二主题尚未验收。
