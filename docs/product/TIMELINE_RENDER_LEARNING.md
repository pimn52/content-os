# 时间线、渲染、复核与反馈

EditPlan 保存场景时长、画面来源、裁切、字幕与图形意图；VideoSpec 锁定帧、实际素材、Master 和输出。先定视觉可行性，再用真实音频/画面时长解算，不靠渲染器猜编辑意图。

## 成片契约

- MasterNarration 是旁白与字幕时间基准。ScenePlan 的内容要求和 EditPlan 的画面选择必须同时满足；缺素材时明确阻塞。
- 人物派发和装配共用实际语句边界，不把生成文件尾部静音另算成人物画面或补卡。对比镜头须覆盖所需时长，删除“覆盖四分之三即可、剩下补图文”的规则；图形须独立规划。
- 选用 Asset/Clip 时核对哈希、项目、时长、构图、历史重复和生成素材 QA；入库授权由 Run 继承留痕，不在选材和成片阶段重复设卡。比较画面按实际播放区间清理，关键帧不能替代整段检查。
- 已指定的播放区间贯穿避重、竖屏衍生和原声对齐；不能再按整段 Clip 随意换开始位置。原字幕裁除在画幅布局前处理，实际文件或画面证据变化后重新预检。
- 自动制作先准备真实素材目录，再写稿与分镜、核验场景用途，最后投入语音、口型。场景遵守所选真实区间的时长，不能先写长场景再扩大短镜头。自动规划不以大字卡填缺；图解须表达关系、过程或信息损失，用户手动图形选择保留。
- 短视频默认竖屏，先解决应景选材和安全的竖屏布局。整片使用同一画幅，横屏仅由创作者明确选择；横版不自动优先换成竖裁衍生片。不能裁掉重点、混剪不同适配目标，或用大字卡替代素材；仍须解决源字幕冲突。
- Render Worker 经正常 Job、预算、幂等和当前来源复核产生输出。技术 QA 检查可解码、时长、音视频与确切输出哈希；本轮成片质量交用户复核，不把逐片人审设成普通自动生产的固定前提。
- 失败、修订与再渲染保留旧输出和账目。同一许可、素材、内容、时轴条件不成立时不得沿用旧审批。短预览仅服务内部检查，不代表完整视频通过。
- 渲染失败可由普通 UI 显式续接：重核相同已保存方案、来源和 QA 后重新装配，仅新建本地渲染任务，保留旧失败，不重跑模型。续接成功不计首次自主出片通过。

## 反馈

复核结论绑定确切成片，可记录意义损失、证据缺失、声音/口型、字幕和构图问题。采用的负反馈只影响对应内容/素材/呈现范围；发布后的表现进入下一次策划，不能篡改旧资产事实。

## 选版、导出与发布

- 自动链路的唯一有效成片自动计入该作品使用；质量结论与发布走向分别记录。
- 用户返工产生同作品候选，支持继续修改与比较。选定时展示选用版锁定、弃用版释放、关联排期变化；仅释放不再被保留作品使用的区间。
- 多版导出展示版本、共享来源和实际冲突，保留各版关系；同作品跨平台或画幅适配不直接算作不同作品重复。
- 走向发布依据已有设置、排期、用户操作与发布任务识别；发布成功依据回执或有来源的发布记录。导出和待审不能直接当作发布或弃用。
- 已发布使用史保留；素材是否允许再次引用按[本次用途](MEDIA_ASSET_SYSTEM.md)判断。

## 当前能力与缺口

Master、EditPlan/VideoSpec、Remotion/FFmpeg、普通 Run 渲染及部分修复已有。9:16 为默认，16:9 须明确选择；已删除按横屏镜头或占比自动改横版的规则。成片仍因选材及字幕问题被打回，基础修复完成前暂停成片实测，见 [STATUS](../../STATUS.md)。
