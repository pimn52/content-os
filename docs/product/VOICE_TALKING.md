# 创作者声音与人物画面

Voice 输出 MasterNarration：与已批准文案、人物授权、实际音频和时间轴绑定。Talking 输出 TalkingRun：包含原始参考、连续片段、画面和复核证据。二者都是普通生产可选择的产品对象，不把提供商子任务直接暴露为成片资产。

## Voice

- 文案意图与提供商时长限制分开。本地克隆按完整场景分段，模型只加载一次；保存每段文案区间、音频、采样区间及哈希，再合成 Master。失败保留已完成片段，不自动重试；合成后仍做全文独立 QA。
- 本地 QA 核验分段 PCM 与 Master 一致后，逐段首轮识别并汇总检查全文；不向识别器提供目标文案。用量保存本次段数，真实缺词仍失败；独立识别边界与连续交付区间分别保留，不把上下文停顿当作识别语句。
- 合格旁白可用本次真实词时标细分长识别段，只在原文自然标点和完整词边界相交处切分；原识别段与词记录保留、时间轴重新绑定哈希，调度、口型和字幕共用。时标缺失、重叠或文字位置不符时保留原段，不按字数估算。词时标仍是识别估计，不代表声音自然度通过。
- 独立 QA 明确定位单个失败段时，普通队列可只重做该段，原样复用其余合格 PCM，重组后重新核验全文；失败证据与调用保留。未知或多段失败不盲目重做。
- 中文等长、同位置替换仅在双方都是单读音且声调一致时记为同音识别差异；多音字、异调、数字和英文仍按原规则，不放宽替换阈值。保存原识别、字面差异及音频/稿件/时间轴哈希，分镜、字幕、口型共用核验事实；不代表人物自然度通过。
- 新调用前核对人物同意、模型权利、当前能力、完整文案覆盖、配置和预算。失败/不明调用不可用新键偷偷重试。
- 独立 ASR/文件 QA 核对文案、音质和确切音频；本次自动执行的技术合格旁白可直接进入自己的待审成片，不等于人工认可或可跨执行复用。U-Voice 对确切 Master 记录相似度、自然度、重音、语速、节奏和停顿。新音频不继承旧结论。
- 技术合格且字数位置可对齐时，字幕用本次生成原文，时间用独立识别结果；ASR 同音错字保留在 QA 证据，不直接变成新字幕。源视频已有字幕需另行核对，关闭新字幕不能消除原字幕冲突。
- 停顿、语气与强调属于编辑意图。建议可修改，不能自动改写原文或承诺精确声学效果。

## Talking

- 新内容需要与确切 Master 片段、授权人像/参考 Clip 和人物同意匹配。新生成表演保持动作自然，不截掉最后一个字；原样事实引用、梗和对照按本次用途判断复用。
- 子片段技术 QA、连续性与人物自然度分别记录；本次执行的确切技术合格输出可进入待审成片，跨执行复用仍须对应人工结论。
- 人像参考只需自然、连续、脸嘴清晰；可以不流利或不说话，声音来自独立的已配置声线。是否自然仍看真实输出，不能把静默素材一概称为已验证。
- 来源集中登记后进入同一动作池，按 Master 实际语句区间跨多条素材分配。分别统计去同源重叠后的可用总时长和最长连续区间，保留合格长区间，不把独立短评估拼成未经证明的连续素材；声音参考独立，静音动作参考可入池。
- 普通素材可登记所属创作者和动作用途；视频整段分析只把明确观察到的合格连续区间入池，单帧和旧短片认可不外推母片。竖屏制作不自动把横屏母片裁成动作参考；真实模型效果仍待验证。
- 改写语音/口型的新表演检查整片参考覆盖和无意重复；不能把所有人物画面都按原片区间机械禁重，也不能用旁白中未出镜的间隔直接抵扣可见动作容量。参考不足时保留表达意图，寻找适当替代。
- 工序为完整文案与镜头意图 → 核心素材可行性 → 克隆旁白及核验 → 按真实时长精排 A/B-roll → 对口型 → 装配、渲染及整片审核。人物容量约束画面调度，不限制文案字数；真实语句按连续窗口和模型单段能力分配，不能裁掉开头或重复动作。未知对齐能力不冒充已验证。
- 实测合句无法分配时，先沿 Master 已核验分句再作一次纯调度；仅对齐能力已知时采用，不猜新切点、不改旁白。确实不足才调整画面，人物调用仍按最终段数核对预算。
- 所有人物窗口先统一校验再入队；已派发窗口固定，重放不生成新任务。Worker 沿同一执行处理人物画面、QA 和渲染，全部必需人物段技术 QA 后才渲染；失败留证，不盲目重试。
- 普通 Run 的交付从前一识别段末尾到本段末尾，首段从零开始、末段保留 Master 尾部；配时、绑定、音频切片和装配一致，完整原文须对应持久段边界。旧显式语句切片保持兼容，旧短片不自动补足新增停顿。
- 当前 LatentSync 参考转 25fps 后按实际帧数覆盖模型窗口，原始输出独立核验画轨帧数与时长，不复制末帧补足交付。帧率转换可能重复采样，不代表循环、可见口型或自然度已验证。
- 输出技术 QA 独立解码画轨，按提供商声明的输出帧率计算覆盖，保存实际帧数、时长与帧率；不能用容器音轨时长或待测平均帧率自证。QA 前后绑定确切文件哈希。未声明帧率、工具失败或证据不明时保留成果，不自动重生。
- 人物短槽不必放开场。开场先完整说明主体和问题，长句用应景画面承载，短槽可在后面作判断或过渡；不能为凑字数留下“越高越清晰吗”这类残句。当前检查覆盖已暴露的比较残句，不代表通用语义审核已完成。
- 不同 Clip 或裁剪片的同源关系统一追溯；占用按[作品与版本规则](MEDIA_ASSET_SYSTEM.md)处理，同作品比较不互抢。已派发窗口保持可追溯；提供商额外帧对齐在记账和推理前检查。
- 修复保留前后素材、调用和判断；已发生或状态不明的模型调用不能当作未发生。短样本的成功不自动外推到长视频。
- 配时取材提交前，在同一事务重核草稿、Run 和 Master；改稿、取消或替换旁白后，旧结果不覆盖新状态。交接错误只停止对应快照，迟到回调不停止已推进的制作。

## 当前能力与缺口

返工要求：素材不合适、重复或占用冲突回到素材调度；时长偏差重新配时并保留合格旁白；声音缺陷修相关语音；口型缺陷修相关人物段；字幕、布局与剪辑错误修改装配后重渲染。只失效真实依赖，局部复检后仍需整片复检。以上为完整落地标准。

Voice、Talking 与装配修复计划现分别声明责任、确切范围、保留成果及待补能力。主观不合格或根因未定位时返回局部修正需求，不再一概要求全文重规划；未知诊断不得派发重生。实拍语义反馈可对照成片、原素材与已核验旁白文字定位素材或装配责任，局部换材后的实际画面可沿普通队列复验；静音观察不能判断声音自然度或口型同步，生成口播、人物及整片的自动质量闭环仍未完成。

成片中的口型不同步可独立登记到确切版本及场景，不混入人物自然度。生成画面与成片装配均可能造成该症状；未对照人物段、旁白及成片定位前保持未知，保留成果，不据此自动重生。

独立 Talking 技术 QA 定位的短画轨、帧率不符或明确无效媒体数据可沿普通 Worker 作一次局部修正；保留合格旁白和其他人物段，重新 QA 后继续装配。已知 QA 失败进入诊断，其他停止原因仍保留；未知错误不借此重发。纯装配重渲染复用声音与人物结果。语音单段修复目前仅支持 Talking 消费之前；已消费后的依赖传播、整片内容自动诊断和修正尚未完成。最终完整解码等技术复检不代替创作质量人审。

池容量只计已登记且适配的区间，长母片不自动等于长合格参考。容量不足时，产品可提出一次有理由的切题实拍备选并重新调度，保留本人出镜和完整旁白；本人表演是否不可替代仍依赖模型判断。上述动作入池、重排与局部语音修复已通过离线队列验证，真实模型和整片效果待验。

现有 Master、独立 Voice QA、确切音频复核、Talking 子任务/预览/整段复核和部分 Run 修复入口。真实运行与人审结论只适用于对应样本和配置。普通 UI 新主题完整 Voice→Talking→成片尚未通过，第二主题未复验。供应商许可与能力须在派发前有可核证记录。
